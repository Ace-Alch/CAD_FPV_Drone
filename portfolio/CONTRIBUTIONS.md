# FPV Quadcopter CAD Design: contributions and reuse

Record personal work, team work, course-provided code and external assets separately. Use a file path or commit as evidence of a specific contribution.

Do not remove author names or license notices. Do not select an open-source license for material without the required rights. Keep personal data, credentials and private configuration out of public commits.

The documentation package does not change the license of any existing artifact.
